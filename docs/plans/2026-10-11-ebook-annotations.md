## 插件实施

- 新增独立布局模块，由完整 `edit()` 在语义识别之后调用。新增 keyword-only `reading_style='standard'` 和 CLI `--reading-style standard|preserve`，既有位置参数和元数据流程兼容；metadata-only 保持正文及资源字节不变。
- 注释引用采用单层 sup 或等价的单次上标样式，默认相对字号 `0.75em`；复用已有 sup，不重复缩小或抬高。引用仍保留真实 href、ID、`epub:type=noteref` 与 `role=doc-noteref`。为已解析引用保留键盘焦点样式，普通数字与普通链接不误判。
- 上标验收覆盖 sup>a、a>sup、a 自带字号/vertical-align 以及 sup 还含其他文字的情形，检查有效字号和升高只应用一次；不能为了标准化引用改动同一 sup 内其他文字的内容或样式。
- 注释目标保留唯一 ID、内容与跨文件关系，规范 footnote/endnotes 语义和角色。集合内条目不错误套用 `doc-footnote`，不生成已废弃的 `doc-endnote`。不全局隐藏注释正文，不注入 EPUB 脚本，也不将 EPUB 锚点改成无目标按钮。
- doc-endnotes 仅用于包含至少一个列表的集合容器，不直接赋给 ol；集合条目原有 EPUB endnote 语义为兼容保留，去除不合适的 doc-footnote/doc-endnote 角色，不新增已废弃的 endnote 词。条目合法的 epub:type=footnote 保留；仅有旧 role=doc-endnote 的已识别目标补此语义但不补错误 ARIA 角色，确保现有阅读器仍识别注释、不把注释正文重复导入章节。独立审核时纠正了原先排除该 TYPE 的判断：SSV 1.1 footnote 明确允许标记 endnotes 分组内条目，EPUB TYPE 和 DPUB ROLE 的限制不能混为一谈。
- 独立插图采用 figure，唯一 figcaption 为最后一个子元素，内部使用 p 保留图注/来源段落。显式 caption 类/语义与明确关联才可归并；不猜测普通相邻段落。原来源可标记 `epub:type=credit`。行内图片、封面、普通正文与未关联段落不移动。
- 不生成 p>figure 或 p>p；已有图注中的 p 直接保留。移动节点需保留 text/tail/ID/href 的内容与顺序。credit 只放在明确来源的 phrasing span 上，来源原段落保持 p。
- 图注使用相对小字号（默认 `0.85em`）、取消首行缩进；图片旁已识别引用复用相同上标规则。不新增图号或来源。缺少或不确定图注可报告说明，不能凭空填充，也不使没有图注的普通书籍无法转换。
- 样式限定在插件标识的节点与文档内，不能覆盖正文全局 CSS。重复编排不增加嵌套 sup、重复 figcaption 或重复样式。图片/图注之间存在未归属正文 tail、重复图注带正文或重排会改变原文顺序时，保留结构并报告 warnings，不能强行归并；普通正文不得成为图注。
- 升级为 0.2.1，保持插件身份、原有提示内容和类型，并同步 README、技能、格式限制和阅读器约定；生成独立 ZIP，保留 0.2.0 验收记录。

## TDD 与验收

1. 插件先写失败测试：上标与比例、已有 sup 去重、图片图注/来源顺序和原字节保留、普通相邻段落不误移、无图注不造内容、跨文件/非 spine 注释、endnotes 角色、metadata-only/preserve、重复处理稳定性。
2. 实现后运行原 EPUB/元数据、转换、book-translator 回归；涉及生成 EPUB 的结构变化时重跑十格式全部 90 方向与图像/注释实际引擎场景。
3. 阅读器若在范围内，先写导入、存储和共享组件的失败测试，覆盖插图与图注、图旁引用、段落下标和注释偏移不漂移、包外/远程资源拒绝，再实现并跑类型/构建检查。
4. 使用插件实际生成 EPUB 作为阅读器测试输入。通过实际组件交互验证正文和图片旁标记：小于正文、位于上方，点击显示正确注释，URL/章节/阅读位置不变化，关闭及键盘行为正确。
5. 浏览器验证只有实际运行后才能宣称通过；静态 EPUB/DOM 测试和实际浏览器呈现分别记录。保存样本、测试结果与未验证的其他阅读器/格式边界。

技能必须给出非 EPUB→暂存 EPUB→edit standard→必要时最终导出的具体命令和报告读取步骤。每一步独立新路径，任何 issues 都阻断后续，不能跳过编排后将纯转换称为已应用本次规则。

## 标准依据

- https://html.spec.whatwg.org/multipage/grouping-content.html#the-figure-element
- https://www.w3.org/TR/epub-ssv-11/#noteref
- https://www.w3.org/TR/dpub-aria-1.1/#doc-endnotes
- https://www.w3.org/TR/epub-rs-33/#sec-structural-semantics
- https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/

EPUB 标准允许阅读器选择是否基于结构语义提供特殊行为，因此实际“点击显示而不跳转”的保证必须来自目标阅读器验收。
