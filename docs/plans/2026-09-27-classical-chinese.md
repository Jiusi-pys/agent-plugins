# 古文精译扩展：实施与审核方案

用户要求：在书籍翻译插件内新增古译今，忠实精译；对现代读者不熟悉的《诗经》《春秋》等用典给出详细解释，真正查阅古籍核验。延续先计划、审核、TDD；Agentic Review 与 EPUB 编排源码不改动。

## 范围

在现有 book-translator 内新增 classical-translate 技能，沿用内部 translation-review 和真实译者/专属章节 reviewer/独立全局 reviewer。文本输入（粘贴后保存、UTF-8 TXT/Markdown）输出原文、现代译文与详注 Markdown；EPUB 输入沿用现有编排流程，输出现代文 EPUB，并在注释中保留原文对照。文本路线不依赖 EPUB 编排。

默认面向初学者，现代文使用简体中文；原文保留繁简、异体和用户底本文字。断句、通假、古今义、虚词、倒装省略、名物制度、纪年人物、引经用典、异文及解释争议单独说明。不能把精译写成大意或把自拟案例冒充古人故事。

## 核心契约

1. 以 `profile.mode=classical_chinese` 显式启用，普通外文翻译及旧作业继续可用。冻结模式，不能删除 profile 字段绕过审核。
2. `sources.json` 保存实查来源，`sources/<id>.txt` 保存实际打开/读取所得必要证据文字或图版核读转写。每项记录书名、作者或注家归属、版本信息、卷篇页/段、URL或本地扫描件引用、访问时间、访问方法和工具轨迹说明及 SHA-256。不知道底本就明确写未知，不能用网页署名推定古籍作者。
3. 每个现代译文片段带 classical 核验记录及可定位的原典证据；解释注释带具体 claim、引文和来源引用。引文必须存在于保存证据中；原典/古注与现代研究分类，只有现代转述不能代替关键原典。引文命中不等于解释成立，必须 reviewer 实际复核。
4. 用典注解释原典发生什么、人物关系、被引用的原话、原语境及当前作者借用的意思。区分《春秋》经文、《左传》《公羊传》《穀梁传》，区分正文、古注、后世评议和现代整理；不同文本/同句不能假定同一解释。争议保留有来源的异说，关键未查明处阻止交付。
5. 引文证据、底本或注释变化使旧审核失效。来源被改写、未实际打开原典、只有搜索摘要、仅凭模型记忆或伪造页码不能记录为已核验。
6. 章节及全局 reviewer 另提供 source_checks，覆盖本次全部引用源的摘要、实际复核方式、定位与结论；正文与典故双重检查。不能复制译者的已读声明当作独立检查。
7. 输出明确分开原文、现代文、详细注释和证据出处，保留定位及返回链接。对网络阻断和版本无从核实的来源如实记录；不虚称完成精校。

## 代码方案

- 复用 book_translate.py 的身份分离、覆盖、审核摘要与导出门禁；扩展 `prepare --mode classical_chinese`、`prepare-text`、`record-source`、Markdown finalize。
- 新增 classical.py，负责文字清点、来源快照/摘要、逐条引用校验、古译今附加门禁和 Markdown 编排。
- EPUB 注释采用已有结构与编辑器，新增详注来源和原文对照，不改依赖插件。
- 新增技能、考据规范、来源/审核数据契约和角色模板，内部 reviewer 增加古译今检查项。
- 版本升为 0.2.0，保留现有身份、两个 starter prompt 及顺序；仅追加古译今入口。当前私有 Plugin Creator release 作为更新基线，发布后读回。

## 方案审核

当前 agent 已按理解、反例、验证三个视角审查本方案，不将其声称为独立模型审核。主要反例及处理：

- 空 citations 或假 URL 冒充考据：要求实际内容快照、定位和引用命中，并以 reviewer 实际浏览轨迹补足机器无法证明的事实。
- 以同一网站两个转载页称为互证：规范明确记录来源关系，必要时比较古注/图版，不能机械数 URL。
- 解释注无引文、古今同字误释、引用断章取义：片段原典核验和详注证据分开，专门审核上下文与解释层次。
- 新模式影响旧外文作业：默认仍为 foreign；旧 schema 兼容，原有全部测试回归。
- TXT 导出强依赖 EPUB：文本独立 prepare/finalize，复用审核而不调用 editor。
- 直接写“已查阅”并不能证明阅读：保存真实工具痕迹和独立复核报告，报告明确区分结构门禁与人/模型阅读。

## TDD 与验收

先测试失败，再实现：文本完整覆盖及原文不变；缺原典/伪造引文/快照篡改/过期证据/缺 source_checks 均阻止通过；歧义无说明拒绝；详注输出有卷篇与链接；原文对照不重复计算为现代译文；旧工作流回归。

实际样本使用含引《诗》的古文，真正打开原文、被引诗篇及古注；由独立 reviewer 复核，输出带来源的现代文。证据不可访问时换可公开访问的古籍来源并说明版本层级，不能用搜索摘要冒充正文。实际未完成的层面单列为 NOT_RUN。
