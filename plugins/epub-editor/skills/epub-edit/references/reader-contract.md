# Jiusi-pys/ebooks 阅读器约定

仓库：https://github.com/Jiusi-pys/ebooks

2026-09-17 的本地适配在原始提交 `33c8fd0` 的基础上完成，尚未推送或部署。最初的导入器仅保存段落纯文本；仅编排 EPUB 无法让旧版阅读器获得弹窗。

适配后的导入流程：

- `parseEpub.ts` 读取正文和非 spine 注释文档，交由 `epubContent.ts` 解析。
- nav 的 `epub:type=toc` 或 NCX 目录转换成 `ParsedBook.outline`，包含章节 ID、段落下标和层级；导入时保存到本地书籍对象。
- `Chapter.paragraphs` 保持字符串数组；可选 `Chapter.footnotes` 包含 `paraIndex/start/end/content`。起止位置是归一化正文的 UTF-16 偏移，内容为纯文本。
- 正文中的 `noteref` 必须关联对应的 `footnote` / `endnote` 目标；即使目标位于独立 XHTML 文件，也要在导入时将其内容映射到正文段落。锚点是导入映射依据，不是用户期望的阅读导航行为。
- `EpubText.tsx` 在引用标记原位置使用相对小字号上标按钮和 Radix Popover，展示注释/翻译纯文本，不注入原始 HTML，也不导航到注释页。普通阅读、参考窗格和双语原文使用同一组件。保留键盘可访问性及可关闭的弹窗行为。
- 旧书的已导入纯文本无法恢复已丢失的锚点和注释，应重新导入处理后的 EPUB；不要自动删除旧书或批注。
- 本次范围是 EPUB 处理与本地导入阅读；不承诺旧 API 客户端或跨设备同步恢复额外阅读信息。

插件侧测试需验证输出保留可解析的正文注释锚点、目标语义与翻译文本。阅读器侧回归需使用插件生成的 EPUB 样本，覆盖非 spine 注释导入、正文原位点击后弹窗显示翻译、且不触发注释页导航；普通阅读、参考窗格和双语视图均需覆盖。

## 0.2.2 配套 Web 阅读器适配

标准编排使用 `figure` 下最后一个 `figcaption`，图注/来源原段落保留为 `p`，来源在 phrasing `span` 上标记 `epub:type=credit`；图注相对字号 `0.85em`，取消首行缩进。已解析引用为 `0.75em` 单次上标，仍有真实 `href` 与 `doc-noteref` 语义。Jiusi 的渲染字号由阅读器组件控制，不能根据 EPUB CSS 推断其实际字号。命令、保留模式及报告读取见 [reading-style.md](reading-style.md)。

2026-10-11 在阅读器基线 `2ffca98c6b64e6f0a21c89ad24c06b96c2114330` 上完成本地适配，尚未提交、推送或部署。使用时先确认实际运行的阅读器包含此改动；插件更新不会自动更新阅读器服务。

- 包内正文 PNG/JPEG/GIF/WebP 按原顺序显示，保留独立图片、行内图片、图注、来源、裸图片旁引用和图片独立章节；不制造图号或来源。
- 图片只来自 EPUB 包内且须列入 manifest。每张 12 MiB、全书 32 MiB、2000 张、边长 16384、每张 40M 像素上限；实际字节类型、尺寸和本地解码均校验。远程/data/file/blob、越界路径、缺失、SVG/不支持类型、损坏或超限明确阻止新导入，不下载远程资源。
- 新增本地 `EpubLayout` v1，记录有序布局和去重图片；不修改 `Chapter.paragraphs` 字符串及 UTF-16 引用偏移，也不向严格镜像章节加入图片字段。布局必须覆盖所有原章节、每个原段落恰好一次，损坏时回落旧文本。
- IndexedDB 11 既有 metadata store 保存 `epub-layout:<bookId>`，与书籍及原文件原子保存；源文件/结构摘要核验，正文或注释变更后失效，删除/tombstone 清理。缓存不进入 outbox/镜像，相同正文回写保留缓存；单纯原文件缓存驱逐不清除布局。
- 主阅读、参考窗和双语原文使用共享组件；双语译文不猜测插图位置。图注实际为 0.85em，注释为 0.65em 上标按钮；图片置于按钮外，按钮显式 `lineHeight: 1` 修复原有零高度点击区域。
- 旧书在新版阅读器中重新导入才能恢复原先丢失的图像；不自动删除或重解析旧书，不改写批注。布局仅本地缓存，其他设备需重新导入，不能宣称跨设备图片同步已实现。

实际验收使用本插件生成的 EPUB，经过真实解析、IndexedDB 和 ReaderView/参考窗/BilingualReader，在隔离 localhost 浏览器中运行。正文 24px、图注 20.4px、引用 15.6px、按钮高度约 15.60px；普通点击与 Enter 打开正确注释，关闭和 Escape 恢复焦点，URL/章节/滚动不变。存储重开、横向分页（翻页关闭弹窗且进度恢复）、双栏及 390px 窄屏阅读布局通过。译文使用合成缓存，不请求 API，未验证真实账号站点、原生端或其他阅读器。

阅读器本地全仓 check/lint/build 通过；当时 703 测试通过、53 跳过。随后这 53 项已在 US 补跑为 49 通过、4 失败、0 跳过：原生 Mirror 必填字段校验差异和三项 MySQL TIMESTAMP 夹具失败。阅读器独立审核发现的 5 项前端 P2 已修复并复测，但这不关闭后续服务集成测试暴露的问题。2026-10-11 插件仓库 US 回归为 279 通过、8 引擎测试跳过（本机 8 项补跑通过），未再次运行或修复阅读器服务测试。EPUBCheck 和真实服务部署不包含在上述通过结论中。

EPUB 结构语义不规定所有阅读器必须弹窗。只有实际阅读器交互验收才能证明标记小于正文、位于上方、点击显示正确注释且 URL/章节/阅读位置不变，以及关闭和键盘焦点行为正确。静态锚点测试不能证明“不跳转”。依据：[EPUB Reading Systems 3.3](https://www.w3.org/TR/epub-rs-33/#sec-structural-semantics)、[WAI 对话框模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)。
