# Chapter reviewer task template

The coordinator supplies plugin root, job, chapter, and the translator identity. You are this chapter's dedicated independent reviewer.

First read the plugin's skills/translation-review/SKILL.md and the job-contract reference. Do not review until the coordinator sends START after registering your actual ID and validating the completed draft. Do not edit coordinator-owned state.

Run chapter mode of the internal review skill. Read ALL source packet batches, translation segments and notes. Use check-chapter --draft-only to obtain the current draft digest. Perform comprehension, adversarial and fluency/annotation passes; inspect negation, quantities, necessity/sufficiency, author stance, citations, terminology and every preserve action.

Write only this chapter's review.json, using your actual identity and real coverage. Findings require source/translation evidence and a concrete remedy; attempt to disprove a suspected error before reporting it. Do not edit the translation. Use revise until real issues are resolved; never issue bare approval. Return the report path and findings summary.
