# Translation Review — 本插件内部审核

仅审查主 agent 指定的 book-translator 作业。使用 [报告契约](references/review-contract.md) 及 `../book-translate/references/job-contract.md`。审核借鉴风险分层、独立复核与证据约束，专门针对翻译内容。

若 profile.mode 为 classical_chinese，必须再读 [古文精译](../classical-translate/SKILL.md)、[实时调度与择优](../classical-translate/references/live-research.md) 及其 [证据契约](../classical-translate/references/evidence-contract.md)。实际独立打开全部引用的原典/古注，审核断句、古今义、典故原语境、经传/注疏归属及异说；填写 source_checks。核对本次两路独立研究、两份候选和逐段择优记录与真实宿主任务轨迹相符。网页搜索摘要、研究者转述或复制别人的复核记录都不能替代本次实际核读；缺少真实过程证据必须 revise，不能仅凭 Python 结构门禁批准。

## 角色与权限

- chapter 模式：每章一个专属 reviewer，不得是该章 translator。
- global 模式：独立的新 reviewer，不得参与过任何章的翻译或章节复审。
- 审阅原文、profile、译文、原注及译者注。只写自己的审核报告，正文修改交回原 translator。
- 不改动独立 agentic-review 插件，不创建独立 marketplace 条目，不编造其 API 调用。
- 等待协调者登记真实身份并发 START；身份字符串本身不证明独立性，需实际宿主任务轨迹。
- 古译今的章节 reviewer 不得是本章研究者或任何候选译者；全局 reviewer 不得参与过任何研究、候选翻译、择优或章节复审。

## 建立审核依据

确认输入摘要、profile、原书版次、读者需求、章节边界和全部 segment 清单。记录所审精确版本，先运行确定性 check 获取摘要与结构结果。结构测试通过不代表译文正确。

主 agent 未提供完整原文/译文或上下文时，将对应范围标为未审；不能仅凭他人报告签发整章/整书通过。长文按批次完整读取并保存已读清单，不能只抽样然后声称全文终审。

## 三个检查视角（不是返工轮数上限）

1. **理解与完整性**：从原文重建含义、论证、语气与作者立场，逐 segment 对照。包含标题、目录、表格、图片说明、原注和附录；明确检查每项 preserve 是否合理。核对命名、数字、引文、否定、条件与量词，避免只比对字数。
2. **反例与准确性**：寻找可能推翻当前译法的上下文，特别是必要/充分、命题/逆命题、事实/假设、作者观点/引用反对观点、多义词与代词。先试图反证候选问题再报告；不要把个人文风偏好升级成错译。
3. **中文阅读与注释**：连读中文，检查指代、句间衔接和自然程度。初学者需要的概念、隐含前提与难点应获得简洁说明；辅助案例应清楚是假设，并在条件与边界上对应原文。核对新增解释是否带入作者未持有的立场、未证实的事实或错误类比。

global 模式重复全文对照，并追加跨章术语与论证发展、重复/遗漏章节、原注/译者注区分、译名证据和全书风格的检查。必须覆盖全部文本，不能只统计章节报告。

## 问题分级与修订

- P1：漏译/多译整段、意义反转、关键概念错译、伪造内容、未经审核即交付等核心错误。
- P2：局部误义、指代错位、注释误导、重要术语不一致、影响理解的不通顺。
- P3：有明确阅读影响的局部改进；不报告纯个人偏好。

每项包含具体 source_quote/译文证据、segment、激活语境、影响、修订建议及置信度。报告可以保留已解决项，但 unresolved 问题不能在 approved 里存在。复杂哲学分歧如无充分证据，记录具体备选与待决问题，不能自行宣布唯一权威译法。

译者返工后从新稿重新检查相关语境并更新整章摘要，必要时复核全文。仅修改报告里的摘要以匹配新稿不算复审。普通外文模式默认三轮仍未解决时向协调者报告具体待决问题。**古译今不设固定返工上限**：按问题继续实时回派研究、比较候选、改稿及复审，不因时间或费用缩减查证。只有可行替代仍无法解除的材料/访问/环境障碍，或需要用户独有的信息时，才报告具体缺口并保存可恢复进度；不可无意义重试或降级通过。

## 输出与界限

报告包括全文实际 coverage、准确性/流畅度/注释结论、已解决和未解决问题、版本摘要与残余不确定性。不存在问题时也给出所读范围、关键核对证据与未验证项，不写“LGTM”式空批准。

审核结果不是发布权限；格式检查、模型语义审核、EPUBCheck 和阅读器验证是不同证据。主 agent 依作业门禁决定是否进入编排。不能声称机器保证“绝对无错译”。
